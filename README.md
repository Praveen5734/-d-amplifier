# Class D Amplifier Design Task

## Overview
This project implements a Class D audio amplifier using discrete components
like NE555, op-amps, MOSFETs, and passive components.

## Tools Used
- LTspice (Simulation)
- KiCad (Schematic & PCB)
- OBS Studio (Screen recording)

## Design Flow
1. Audio pre-amplifier
2. Triangle wave generation (NE555)
3. Comparator (PWM generation)
4. MOSFET switching stage
5. LC output filter
6. PCB design and verification

## Component Selection Logic
- NE555 chosen for stable PWM carrier
- IRFZ44N selected for low Rds(on)
- LC values selected based on cutoff frequency
